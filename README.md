# 🛠️ Java Debugging & Practice Challenges

Welcome to the **Java-Debugging** repository! This project is a dedicated space for practicing core Java programming concepts, solving syntax challenges, mastering logical control flow, and fixing common coding bugs.

---

## 📂 Project Structure

This repository is organized into structured modules covering progressive Java concepts:

*   **`01-Syntax-Basics/`**: Exercises and challenges focused on learning and debugging fundamental Java syntax, data types, and operations.
*   **`02-If-Statements/`**: Logic-oriented challenges and solutions practicing conditional branching, nested structures, and control flow.
*   **`03-loops/`**: Practical exercises to master loops (`for`, `while`, `do-while`) and iterative logic.
*   **`BmiCalculator.java`**: A practical application that calculates Body Mass Index (BMI) based on dynamic user input, showcasing calculations, formatting, and validation.
